## Traps learned tonight (each cost real time)

1. **The scan wrote the ledger row, then posted; a redeploy between the two lost the post forever.**
   Fixed by the pending flag (#233). Under the old code `announcedAt` was stamped whether or not
   Telegram accepted the send — so an `announcedAt` from before #233 is not proof of delivery.
2. **Wallets differ in what `signTransaction` returns.** Never call `partialSign`/`serialize` on it
   raw; go through `CluckWallet.asTransaction(signed, tx)`. Test: `scripts/wallet-standard-test.cjs`.
3. **Standard-only wallets were invisible on all 21 pages** for as long as the registry existed.
   Wallet Standard discovery lives in `cluck-wallet.js` now; add wallets there, never in a page.
4. **A vault `paused` flag fails open** (`getState()` defaults `{}`); a durable stop is an env var
   or a code default. `lastTickTs` cannot prove a stop. Verified by an adversarial read-only pass.
5. **CI: headless tests need the playwright step.** Anything that launches Chromium must sit after
   `install playwright + chromium` AND carry its `if: steps.gate.outputs.run == 'true'`.
6. **The count guard now reads the tutor prompt and the i18n keys** (#213). Editing English copy
   that carries a number silently drops six languages unless the keys move with it.
7. **Squash-merges make `develop` diverge**: after every promotion, `git merge -X ours origin/main`
   into develop and push. `develop` must read 0 behind.
8. **`pkill -f 'node server.js'` kills the shell that ran it** (the pattern matches itself). Use
   `ps -eo pid,args | awk '$2=="node" && $3=="server.js"'`.
9. X account has Premium — brand posts may exceed 280; the card's counter is for lockers.
