## 1. HOW TO VERIFY — the rule that has to hold

`node normie-quest/test/nq-verify.cjs <baseUrl>` reads the git diff and picks the checks:

| what changed | what it runs |
|---|---|
| one level's data in `LEVELS` | syntax + build + geometry + **that level only** |
| `game_logic.js` outside `LEVELS` (shared code) | syntax + build + geometry + **all 82** |
| assets only | syntax + build + **1 smoke level** |
| tests / docs | syntax only |

`--dry` prints the plan. `--against origin/main` plans a whole branch.

**Two habits that cost the day:**
1. **Don't run the full suite by reflex.** It was run in full for an icon swap, an item removal and a
   banner layout — none could break level 40. Let the tool decide.
2. **BATCH changes, then run ONCE.** The single biggest waste was: make a change, start a 13-minute
   run, think of another change, kill it, repeat. Five starts, four kills, ~40 minutes for a 13-minute
   check.

**The state test is parallel** (`NQ_WORKERS`, default = half the cores). A `NO-LOAD` retries once on a
fresh browser at 90s before being believed and prints `(retried)`; on a 4-core box ~1 level in 9 needs
it. A bare `NO-LOAD` survived the retry and is probably real — confirm with `NQ_WORKERS=1`.

## 3. WHAT IS ON THE BRANCH (17 commits, unverified)

**Security — 2 criticals, hand-verified before fixing**
- `/api/verify-sol-payment` had **no replay guard**. CLKN always consumed signatures via `sigStore`;
  the SOL path returned success without marking them spent. `SOL_UNLOCK_WALLET` is hardcoded in a
  public repo → anyone could replay any historical ≥0.05 SOL transfer to it forever. One real payment
  was a master key to Buy Special. Now `sigStore.add("sol:"+sig)`.
- **Every rate limiter was IP-spoofable.** `trust proxy: true` makes `req.ip` the client-supplied
  leftmost XFF entry, so any `X-Forwarded-For` header bought a fresh bucket — the global 150/min cap,
  the 20/min payment cap and the 15/min forensic caps (which exist to stop draining paid
  Helius/ST/Bags quota) were decorative. Now keyed on the LAST hop. `normie-quest/routes.js` had
  already fixed this for its own throttle; `server.js` never got it.

**Boss pits — fixed at the cause.** All **14** arena-wall constructions collided with `self.player`
only, so no boss was ever penned. Now one `makeArena()` + a per-frame `penBoss()`. Stale
`rugking`/`worm`/arena state is cleared per level (Phaser reuses the scene instance, so a boss left
alive survived into the next level and the guard would pen the ghost). Verified adversarially: 6/6
bosses shoved 4000px out and below the floor, all recovered.

**Gameplay fairness.** `honeypotHit` was the only hazard missing `moonUntil` — Star Power said
"INVINCIBLE" while a honeypot drained the level's coins. Bitcoin Maxi and the casino Drink Lady

**Feature.** Resume-on-the-level-you-died-on (tier 2 / VIP). Gate is on the READ in `gameOver`, not

## 6. TRAPS — don't rediscover these

- `game_logic.js` is **not plain JS** (it has `<script>` blocks). `node --check` fails on it — use the
  split-and-`new Function` check inside `nq-verify.cjs`.
- The **10s idle auto-pause** freezes `update()`. A headless probe that sends no input sees nothing
  happen and it looks like a product bug. Nudge input.
- **Scene transitions are not instant.** Poll `__NQ_DBG().level` until it matches before acting; a
  fixed `waitForTimeout` hits the previous scene. Cost three false failures.
- Phaser's WebGL canvas **does not preserve the drawing buffer** — pixel readback outside a frame is
  meaningless. Inspect the scene graph.
- `pkill -f <pattern>` **matches its own command line** and kills the run you just started (exit 144).
  Use `ps -eo pid,args | awk '...'` + `kill`.
- Served HTML is **~8MB** (assets inlined as base64); each new plate adds ~200KB and the test parses it
  per browser restart.
- **Never rebuild while a regression is running** — it rewrites the served HTML under the test.
