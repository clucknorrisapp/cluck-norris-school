## 1. HOW TO VERIFY A CHANGE — do this, not what feels thorough

```bash
PORT=3111 node server.js &                                   # once
node normie-quest/test/nq-verify.cjs http://localhost:3111   # after every change
```

`nq-verify.cjs` reads the git diff and picks the checks the change actually needs:

| what changed | what it runs |
|---|---|
| one level's data in `LEVELS` | syntax + build + geometry + **that level only** |
| `game_logic.js` outside `LEVELS` (shared code) | syntax + build + geometry + **all 82 levels** |
| assets only (`src/assets`, `public/worlds`, `public/sfx`) | syntax + build + **1 smoke level** |
| tests / docs | syntax only |

It parses the `LEVELS` array from git **and** from the working tree and diffs per level, so editing
3-3's pits tests 3-3 — not 82 levels. `--dry` prints the plan without running. `--against origin/main`
plans for a whole branch.

**Why this exists:** the full 82-level state test takes ~15 min serially. On 2026-07-27 it was run in
full for an icon swap, an item removal and a banner layout — none of which could break level 40. A
tiered rule was agreed verbally, then not followed, because "is this risky enough?" is a judgement
call made by someone who wants to get on with it. The tool removes the judgement. **Do not go back to
running the full suite by reflex, and do not skip verification because the tool said one level —
that IS the verification.**

### The state test is parallel now — and it can lie if you over-subscribe
`nq-state-test.cjs` shards across `NQ_WORKERS` browsers (default: **half the cores**). The first
parallel attempt used cores-1 and starved each browser, tripping the 25s level-build timeout and
reporting **2-2, 4-2 and 5-2 as NO-LOAD when all three pass serially.** The boot timeout now scales
with worker count. If you ever see scattered NO-LOADs, suspect contention before suspecting the game:
re-run with `NQ_WORKERS=1` to confirm.

## 5. TRAPS — hard-won today, don't rediscover

- `game_logic.js` is **not** plain JS — it contains `<script>` blocks. `node --check` fails on it. Use
  the split-and-`new Function` check (in `nq-verify.cjs`).
- The **idle auto-pause (10s)** freezes `update()`. Any headless probe that sends no input will see
  nothing happen and look like a product bug. Nudge input.
- Scene transitions are **not instant**. Always poll `__NQ_DBG().level` until it matches before acting;
  a fixed `waitForTimeout` hits the previous scene. Cost three false failures today.
- Phaser's WebGL canvas **does not preserve the drawing buffer** — pixel readback outside a frame is
  meaningless. Inspect the scene graph instead.
- `pkill -f <pattern>` matches **its own command line** and kills the run you just started (exit 144).
  Use `ps -eo pid,args | awk '...'` + `kill`.
- The served HTML is **~8MB** (all assets inlined as base64). Every new boss plate adds ~230KB and the
  test parses it once per browser restart.
