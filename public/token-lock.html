MAKE YOUR TOKEN METADATA IMMUTABLE

Scanners warn that “the creator can change this token”. If that's not true of yours any more, prove it on-chain. Free, no signup, no wallet needed to look.

READ THIS FIRST — IT IS PERMANENT

Locking metadata is irreversible. Afterwards nobody can change your token's name, symbol, logo, description or creators — not a hacker, not a future you. There is no undo, no support ticket, no recovery.

Don't do this if you might rebrand, you're still settling on artwork, the project is early and the name could change, or someone else needs to be added as a creator later. A mutable token is not a broken token — plenty of good projects stay mutable on purpose.

Do this if your name, ticker and art are final and you want holders to be able to verify that for themselves. That's the whole benefit: it turns “trust us” into something checkable.
