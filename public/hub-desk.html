SEND — signed in your wallet

        
The connected operator wallet pays. Each transaction that confirms is recorded on the server immediately, row by row, with its signature, after the server checks it on-chain. If anything fails part-way, the rows that landed are paid and the rest stay owed — press SEND again to send only what is left. SIGN AND SEND FROM MY WALLET is the same idea through a two-step handshake: the server hands back the exact transfer parameters first (blocking the managed payer and CLOSE BATCH until this resolves — recording a signed row, or waiving one, still works), your wallet signs and broadcasts, and the server only ever observes the signatures you report back — it never holds a key that could move this. Only the project's own FUNDING wallet can use it.
